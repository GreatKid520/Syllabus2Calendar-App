# Scope Document: Syllabus2Calendar

## Project Vision
Syllabus2Calendar transforms unstructured academic syllabi into prioritized, interactive study plans and standard `.ics` calendar events.

## In-Scope Features (V1 Hackathon Release)
- Client-side plain text syllabus parsing.
- Automated extraction of dates, assignments, exams, and projects.
- Sub-milestone task breakdowns with completion checkboxes.
- Dual-view interface: Card list view and visual Gantt/Timeline view.
- Export options for standard `.ics` calendar files with customizable reminders.
- Zero-backend web app architecture deployed on GitHub Pages.

## Out-of-Scope (Future Iterations)
- Server-side multi-user authentication.
- Direct LMS integrations (Canvas, Blackboard, Moodle API sync).
- Push notifications via SMS/Email.
