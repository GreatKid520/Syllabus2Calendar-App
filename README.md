# 📅 Syllabus2Calendar

> **Turn chaotic course syllabi into structured, actionable study timelines and 1-click `.ics` calendar exports.**

Built for the **Devpost Learn AI Basics Hackathon**.

---

## 🌟 Overview

**Syllabus2Calendar** helps students transform messy, unstructured course syllabus text into prioritized study plans and `.ics` calendar files compatible with Google Calendar, Apple Calendar, and Outlook.

### Key Features
- **Smart Text Parser:** Extract dates, assignments, and exams automatically.
- **Milestone Breakdown:** Splits large projects into manageable prep milestones with sub-task checklists.
- **Dual View Modes:** Toggle between detailed assignment cards and an interactive timeline.
- **1-Click `.ics` Export:** Instant calendar download with custom reminder alerts.
- **Zero-Lag Dark UI:** Liquid glass sapphire aesthetic designed for high readability.

## ⚡ Quick Start

No installation required! 

1. Clone or download this repository.
2. Open `index.html` in any web browser (Safari, Chrome, Firefox, Edge).
3. Paste a syllabus or click **"Try Sample Syllabus"** to generate your timeline.
