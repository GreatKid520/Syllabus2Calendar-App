# Scope Document: Syllabus2Calendar

## Project Overview
Syllabus2Calendar converts unformatted text syllabi or uploaded documents into structured calendar deliverables and customizable study milestones. It solves student cognitive fatigue by automating task breakdown and schedule generation.

## Core Scope & Boundaries
- **In-Scope (Current Release):**
  - Text parsing & date extraction for deadlines, weighted assignments, and exams.
  - Interactive milestone task creation with checked progress tracking.
  - Estimated study hour allocation based on assignment weighting.
  - Standard RFC 5545 compliant `.ics` calendar file export.
  - Liquid sapphire dark mode UI with interactive Timeline visualization.
- **Out-of-Scope (Future Iterations):**
  - Direct 2-way Google OAuth live calendar sync.
  - Multi-user authentication database.
  - Canvas / Blackboard LMS API integrations.

## Key Delivery Metrics
- Zero external backend required (100% client-side parser & ICS engine).
- Full compliance with standard iCalendar specifications.
# Product Requirements Document (PRD): Syllabus2Calendar

## 1. Problem Statement
Students waste hours every term manually reading syllabi, calculating study prep timelines, and entering individual deadlines into calendar applications.

## 2. Target Audience
- High school, undergraduate, and graduate students taking multiple active courses.
- Self-paced learners managing independent coursework deadlines.

## 3. Core Functional Requirements
1. **Syllabus Parsing:** Paste or upload syllabus text to extract key deliverables and exam dates.
2. **Sub-Milestone Breakdown:** Automatically generate 2-3 logical preparation sub-tasks per deliverable.
3. **iCalendar Export:** Download clean RFC 5545 compliant `.ics` files with automated reminder alerts for Apple Calendar, Google Calendar, and Outlook.

## 4. UI & Technical Standards
- Responsive single-page web application.
- Modern dark-mode interface with customizable category badges and interactive timeline controls.
# Technical Specification (SPEC): Syllabus2Calendar

## System Architecture
```
[User Input / File Drop]
          │
          ▼
[Parsing Engine]
          │
          ├──► [Milestone & Sub-Task Generator]
          ├──► [Prep Hours Estimator]
          │
          ▼
[State Management & Timeline View]
          │
          ▼
[RFC 5545 ICS Engine] ──► [.ics File Download]
```

## Data Schema
```json
{
  "id": "item-101",
  "title": "Midterm Examination",
  "date": "2026-10-28",
  "category": "Exam",
  "weight": "25%",
  "estimatedHours": 12,
  "subtasks": [
    { "id": "st-1", "title": "Review Lecture Notes Ch 1-6", "done": false },
    { "id": "st-2", "title": "Complete Practice Problem Set", "done": false }
  ]
}
```

## Calendar Export Engine
- Format: iCalendar (.ics) RFC 5545 standard.
- Alarm Trigger: `VALARM` offset (-1 to -3 days before event start).
